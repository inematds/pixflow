A still image becomes cinematic film — no AI video

PixFlow recreates pixflow.net’s effects quality in open-source code: real 2.5D parallax, grain, color grading, vignette, chromatic aberration, bloom, camera movements, and transitions. All motion is built programmatically — render deterministic, without Runway, Kling or Sora.

What it is

Real motion, without hallucination

AI video generators invent pixels (and errors). PixFlow does the opposite: it starts with your image and moves it with real depth, reproducibly. v1: image → film. v2: the same engine accepts video instead of a photo.

🌌 Real 2.5D parallax

Generates the depth map for each image (Depth-Anything-V2, via transformers.js, without torch) and separates the layers by depth.

🎨 Cinematic look

Color grading, grain, vignette, chromatic aberration and bloom — 6 ready-made looks with adjustable intensities.

⚙️ Deterministic and local

WebGL/GLSL → Remotion → FFmpeg → MP4. Same input, same video. No API key.

How it works

From spec to MP4

You provide images + a "motion script" (movie spec YAML) — scenes, text, looks, cameras, durations — and the engine assembles the film. Cameras: push-in, pull-out, ken-burns, pan, dolly, orbit, float, handheld, static. Transitions: cut, crossfade, dip-to-black.

movie spec (YAML)→ Depth-Anything-V2→ WebGL / GLSL→ Remotion→ FFmpeg→ MP4
Prerequisites

What you need to run it

Tested on Linux aarch64 (NVIDIA GB10 / DGX). On this architecture, the CLI reuses a Playwright Chromium on its own — or set PIXFLOW_CHROME.

📦 Node + dependencies

Install the engine and CLI pixflow-motion.

cd skill && npm install

🧩 Chromium

Remotion renders in headless Chrome. On aarch64, the CLI resolves it on its own.

# or: export PIXFLOW_CHROME=/path/chrome

🖼️ Images + spec

You bring the images and the movie spec. The render doesn’t generate images or a script.

# examples/demo.movie.yaml
User guide · step by step

From scratch to film

Real CLI commands pixflow-motion. The full movie spec schema is in skill/SKILL.md.

1

Install the dependencies

Once, inside the skill folder.

cd skill && npm install
2

Check the environment

Checks depth, Chromium and FFmpeg before rendering.

node cli/pixflow-motion.mjs check-deps
3

Write the movie spec (YAML)

Scenes with an image, look, camera, duration, transition and caption (kicker/title/body).

# scene: { image, look: cinema-dramatico, camera: push_in, dur: 4 }
4

Render the MP4

Generates depth, applies parallax + look + transitions, and exports via Remotion + FFmpeg.

node cli/pixflow-motion.mjs render ../examples/demo.movie.yaml ../examples/demo.mp4
Looks & limits

The library — and the honest boundary

PixFlow is the final render stage, not the entire factory. Knowing what it does (and what it doesn't do) is what prevents frustration.

🎨 Looks & cameras

# 6 looks
cinema-dramatico · sci-fi-cyberpunk · noir-film
retro-vhs · sonho-etereo · acao-epico

# 9 cameras
push_in · pull_out · ken_burns · pan · dolly
orbit · float · handheld · static

✅ Does / ❌ doesn’t

✅ depth map + parallax 2.5D
✅ look (grade/grão/vinheta/bloom) + transições
✅ legenda (fade) + áudio se você apontar
────────────────────────────
❌ não gera as imagens (você traz)
❌ não escreve o roteiro/spec
❌ não tem narração/TTS

Everything that comes before (idea → script → images → narration) is what the videoprodutor orchestrates.
