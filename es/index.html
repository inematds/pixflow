Skill de Claude Code · render en código abierto

Una imagen estática se convierte en película cinematográfica — sin IA de video

PixFlow recrea la calidad de los efectos de pixflow.net en código abierto: parallax 2.5D real, grain, color grade, viñeta, aberración cromática, bloom, movimientos de cámara y transiciones. Todo el movimiento se construye de forma programática: render determinístico, sin Runway, Kling o Sora.

Qué es

Movimiento real, sin alucinaciones

Los generadores de video con IA inventan píxeles (y errores). PixFlow hace lo contrario: parte de tu imagen y la mueve con profundidad real, de forma reproducible. v1: imagen → película. v2: el mismo motor acepta video en lugar de la foto.

🌌 Parallax 2.5D real

Genera el mapa de profundidad de cada imagen (Depth-Anything-V2, mediante transformers.js, sin torch) y separa las capas según su profundidad.

🎨 Estilo cinematográfico

Color grading, grano, viñeta, aberración cromática y bloom — 6 looks listos con intensidades propias.

⚙️ Determinístico y local

WebGL/GLSL → Remotion → FFmpeg → MP4. Misma entrada, mismo video. Sin clave de API.

Cómo funciona

Del spec al MP4

Tú das imágenes + un «guion de movimiento» (movie spec YAML) — escenas, textos, estilos, cámaras, duraciones — y el motor arma la película. Cámaras: push-in, pull-out, ken-burns, pan, dolly, orbit, float, handheld, static. Transiciones: cut, crossfade, dip-to-black.

movie spec (YAML)→ Depth-Anything-V2→ WebGL / GLSL→ Remotion→ FFmpeg→ MP4
Requisitos previos

Qué necesitas para ejecutarlo

Probado en Linux aarch64 (NVIDIA GB10 / DGX). En esta arquitectura la CLI reutiliza por sí sola un Chromium de Playwright — o define PIXFLOW_CHROME.

📦 Node + dependencias

Instala el motor y la CLI pixflow-motion.

cd skill && npm install

🧩 Chromium

Remotion renderiza en Chrome headless. En aarch64 la CLI lo resuelve por sí sola.

# o: export PIXFLOW_CHROME=/path/chrome

🖼️ Imágenes + especificaciones

Tú aportas las imágenes y el movie spec. El render no genera imágenes ni guiones.

# examples/demo.movie.yaml
Guía de uso · paso a paso

De cero a la película

Comandos reales de la CLI pixflow-motion. El esquema completo del movie spec está en skill/SKILL.md.

1

Instala las dependencias

Una vez, dentro de la carpeta de la skill.

cd skill && npm install
2

Revisa el entorno

Confirma depth, Chromium y FFmpeg antes de renderizar.

node cli/pixflow-motion.mjs check-deps
3

Escribe el movie spec (YAML)

Escenas con imagen, look, camera, duración, transición y caption (kicker/título/cuerpo).

# scene: { image, look: cinema-dramatico, camera: push_in, dur: 4 }
4

Renderiza el MP4

Genera el depth, aplica paralaje + look + transiciones y exporta mediante Remotion + FFmpeg.

node cli/pixflow-motion.mjs render ../examples/demo.movie.yaml ../examples/demo.mp4
Looks y límites

La biblioteca — y el límite honesto

PixFlow es el etapa final de render, no toda la fábrica. Saber qué hace (y qué no hace) es lo que evita la frustración.

🎨 Estilos y cámaras

# 6 looks
cinema-dramatico · sci-fi-cyberpunk · noir-film
retro-vhs · sonho-etereo · acao-epico

# 9 cámaras
push_in · pull_out · ken_burns · pan · dolly
orbit · float · handheld · static

✅ Hace / ❌ no hace

✅ depth map + parallax 2.5D
✅ look (grade/grão/vinheta/bloom) + transições
✅ legenda (fade) + áudio se você apontar
────────────────────────────
❌ não gera as imagens (você traz)
❌ não escreve o roteiro/spec
❌ não tem narração/TTS

Todo lo que viene antes (idea → guion → imágenes → narración) es lo que el videoprodutor orquesta.

Roadmap · ecosistema

MVP funcional y lo que viene

PixFlow es la pieza de render en código abierto. Complementa mdd (dirección), video-plan-editor (estrategia/beat sheet) y promptprof (refinamiento del prompt).

✅ MVP
Render de punta a puntaDepth + paralaje 2.5D + 6 looks + 9 cámaras + 3 transiciones + subtítulos + audio → MP4 determinista.
⏳ Efectos
Transiciones GLSL + overlaysGlitch, whip, zoom-blur, partículas y filtraciones de luz en overlay.
⏳ Color
LUT .cube + sincronización con el beatColor grading con LUT y sincronización de cortes con la pista.
⏳ Avanzado
Segmentación SAM2 + exportación OTIOCapas por objeto e interoperabilidad con NLEs.
