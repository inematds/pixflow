## RESUMO GERAL DE PADRÕES
- **78 shots**, média ~1.9 s/shot, **~31 cortes/min** (ritmo rápido de ação/aventura).
- **Movimentos dominantes:** Dolly/Tracking (seguir), Push-in/Zoom (emoção), Pan/Tilt (revelar), Crane/Aerial (escala), Estática (peso).
- **Arco:** teaser rápido → mundo/maravilha → personagens/emoção → ameaça/destruição → clímax → declaração final → logo.
- **Velocidades:** normal/rápida predomina; câmera lenta em momentos de impacto/fala.

## RECEITA PARA RECRIAR
- **Composição:** ~20% wide/estabelecimento, ~30% médio, ~40% close, ~10% extreme close.
- **Movimento por tipo:** wide → dolly out/crane up/tracking; médio → dolly in/out, tracking, handheld; close → push-in (emoção); extreme → push-in sutil.
- **Duração:** ação 0.5–1.5s; mundo/emoção 2–4s; fala/impacto 3–5s (lenta); logo 4–8s; média ~2s.
- **Ordem:** teaser → mundo → personagens → apostas/destruição → clímax → declaração → título/créditos.
- **Estilo geral:** "cinematic, vibrant, bioluminescent, epic fantasy, high detail, film grain, depth layers".
